📱 ADB 命令

日志抓取
抓取全部日志
adb logcat -b all >log.txt
抓蓝牙完整日志
adb logcat -b main -b system -b events -b radio -v threadtime > bluetooth_full.log
抓kernel日志
adb shell logcat -b kernel >log.txt
过滤音频状态变化
adb logcat | findstr "EVENT_TYPE_AUDIO_STATE_CHANGED"
导出蓝牙dump
adb shell dumpsys bluetooth_manager > bluetooth_dump.txt
导出内核dmesg
adb shell dmesg > android_kernel.log
开启SDK日志
adb shell setprop isSDKLogEnabled true
开启广告SDK日志
adb shell setprop persist.adsdk.log.enabled true
开启hotfix日志
adb shell setprop persist.hotfix.log true
导出系统版本+APK版本
adb shell "cat /proc/version" >> version.txt adb shell "dumpsys package |grep -E 'pkg=|versionCode='" >> APKversion.txt
OTA 升级相关
remount 后恢复 verity（OTA前必做）
adb root adb enable-verity adb reboot # ⚠️ 用过 adb remount 之后如果要做 OTA # 必须先执行以上命令，否则报 kInstallDeviceOpenError (7)
remount 修改系统文件
adb root adb remount # ⚠️ 完成后记得 adb enable-verity + reboot 再做 OTA
截图与文件
截图
adb shell screencap /sdcard/test.png adb pull /sdcard/test.png
推送/拉取文件
adb push <本地文件> <设备路径> adb pull <设备路径> <本地路径>
拉取build.prop并修改后推回
adb root adb connect 192.168.x.x adb remount adb pull /system/build.prop . adb push build.prop /system/build.prop
系统设置
切换环境 dev/acc/prod
adb shell setprop persist.sys.zeasn.pc.env dev # 可选值: dev / acc / prod
查看属性
adb shell getprop ro.vendor.zeasn.pjt.auth adb shell getprop | grep env
调整hotfix更新间隔
adb shell setprop persist.hotfix.update 60000 # 单位毫秒
关闭温度过高弹窗 (PID4)
adb shell setprop persist.sys.ntcfan.check false adb shell setprop persist.sys.ntcfan.exception false
kernel模式下开启ADB
settings put global adb_enabled 1
查看屏幕分辨率/DPI
adb shell wm size adb shell wm density
查看可用内存
adb shell cat /proc/meminfo | grep "MemAvailable"
App 操作
Monkey压测 (appgallery)
adb shell monkey -v -v -p com.zeasn.whaleos.appgallery --ignore-crashes --ignore-timeouts -s 1000 --throttle 50 150000 >monkey.txt
打开App Installer
adb shell am start -n com.droidlogic.appinstall/.main
打开系统设置
adb shell am start -n com.android.tv.settings/com.android.tv.settings.MainSettings
查看aivoice版本
adb shell pm dump com.whaletv.aivoice | grep versionName
发送按键事件
adb shell input keyevent KEYCODE_BACK adb shell input keyevent KEYCODE_ENTER
烧Widevine/MGKID/HDCP key
tee_provision -i /storage/A5EB-3927/<keyfile.enc>

🔌 串口命令

烧写 KEY
烧OTA Key
cd /sys/class/unifykeys/ echo IDX_OTAKEY_NAME > name echo <key_value_1> > write echo <key_value_2> > write reboot
读取/验证OTA Key
cd /sys/class/unifykeys/ echo IDX_OTAKEY_NAME > name cat read
删除OTA Key
cd /sys/class/unifykeys/ echo IDX_OTAKEY_NAME > name echo "0" > write
烧MAC地址
cd /sys/class/unifykeys/ echo mac > name echo "XX:XX:XX:XX:XX:XX" > write reboot
烧MAC (tkconfig方式)
mount -o rw,remount /tkconfig chmod 777 /tkconfig echo <MAC无冒号> > /tkconfig/macaddr.txt sync
切换PID
su echo "pid" > /sys/class/unifykeys/name echo "<pid_number>" > /sys/class/unifykeys/write rm /mnt/vendor/param/pid_updated.txt rm /mnt/vendor/param/panel/* reboot
系统调试
挂载tkconfig为可写
mount -o rw,remount /tkconfig chmod 777 /tkconfig
uboot开启OTG/UART抓log
setenv otg_device 1; setenv UARTOnOff 1; saveenv; reset
uboot切换model_name
setenv model_name FHD saveenv reset # 可选: FHD / UHD_2RG / Z_PANEL
切屏参 (uboot)
xsave panel index <X>
关闭OSD
# 进入 debugmenu @ 10 -> 3 -> 22.PLAT_OSD -> 4.OSD enable -> 输入0 # 1=开启 / 0=关闭
开启9222/7788调试端口
/mtd_apexe/board/iptables -A INPUT -p tcp --dport 9222 -j ACCEPT /mtd_apexe/board/iptables -A INPUT -p tcp --dport 7788 -j ACCEPT
查内存 (procrank)
procrank # 或 cat /proc/meminfo | grep "MemAvailable"
刷board.img / 正常版本
# 刷board.img (uboot下) ewrite ap0 # 刷正常版本 (uboot下) nvt_eburner
切默认遥控器
mount -o remount,rw /tclconfig rm -f /tclconfig/project_id/rcu/key.R* sync reboot -f
删除软链接
cd /mtd_rwarea/apdat/ui rm -rf zeasn.static.page
压测内存监控（串口）
每小时输出一次内存信息（压测用）
su while true; do cat /proc/meminfo echo m > /proc/sysrq-trigger cat /proc/pagetrace dumpsys meminfo top -b -n 1 sleep 3600; done &
sysmonitor内存泄漏监控
nohup /data/sysmonitor.sh -p /mnt/media_rw/<USB>/netflix_memory_leak -m top,vmstat,pressure,mem,pagetrace,dumpsys,kvmstat,slabinfo -app c2,surfaceflinger,mediaserver -app_info meminfo,maps -logcat -dmesg -t 20 1>/dev/null &
U盘读写速度测试
# 写入1G文件到U盘 dd if=/dev/zero bs=1k count=1000000 of=/storage/<USB>/1Gb.file # 从U盘读取 dd if=/media/sda1/1Gb.file bs=64k count=1000000 of=/dev/null
